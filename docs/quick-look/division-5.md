# Division 5 – Röd nivå

**Snabbkoll inför match** · Västernorrland 2026/27

| | Gäller |
|---|---|
| Spelform | 5 utespelare + målvakt |
| Speltid | **3 × 15 min effektiv tid** |
| Paus | 5 minuter; inget sidbyte |
| Byten | Flygande |
| Plan | 18 × 36 m |
| Mål | 160 × 115 cm |
| Sekretariat | iBIS Online; resultattavla |
| Domare | 2, tillsatta av VIBF |
| Ledarutbildning | Grundutbildning barn/ungdom + Steg 1 Röd (eller högre nivå) |

**Originalkälla:** [Västernorrlands ungdomsmatris 2026/27, sida 1](https://www.innebandy.se/media/bjoi2qrd/matris-ungdom-2026-27-med-arvoden.pdf#page=1) *(Finns på [VIBF: Matris – Serieöversikt](https://www.innebandy.se/vasternorrland/tavling/matris-serieoversikt).)*.

## Tre saker att inte missa

- **Läs anpassningarna för division 5** på [matrisens sida 2](https://www.innebandy.se/media/bjoi2qrd/matris-ungdom-2026-27-med-arvoden.pdf#page=2) *(Finns på [VIBF: Matris – Serieöversikt](https://www.innebandy.se/vasternorrland/tavling/matris-serieoversikt).)*, bland annat om målvakt som senare spelar ute, protokoll och utvisningar.
- Alla spelare ska ha **licens och skyddsglasögon**, och laguppställningen ska vara inne i iBIS i god tid.
- Vid hemmamatch: **två matchvärdar med rosa västar** och bemannat sekretariat.
