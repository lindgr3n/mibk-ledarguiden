# Tydlig hierarki för regelkällor

Ledarguiden skiljer uttryckligen mellan nationella regler från Svensk Innebandy, distriktsanpassningar från Västernorrlands IBF och Moälvens föreningsvägledning. När en distriktsanpassning skiljer sig från den nationella utgångspunkten visas båda tillsammans med giltig nivå eller division, originalkälla och kontrolldatum; motstridiga källor märks som obekräftade tills distriktet har klargjort vad som gäller. Detta gör att ledaren ser den lokalt gällande regeln utan att föreningens råd eller guidens tolkning framstår som bindande regeltext.
