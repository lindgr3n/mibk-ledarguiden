# Säsongsindelat innehåll med stabila aktuella adresser

Ledarguidens innehåll delas upp per säsong eftersom regler och lokala rutiner förändras. Enkla adresser som `/rod` visar alltid den aktivt publicerade säsongen, medan tidigare säsonger bevaras oförändrade under permanenta arkivadresser som `/sasonger/2026-2027/rod`; nästa säsong förbereds som ett dolt utkast och aktiveras genom ett medvetet publiceringsbeslut. Detta gör aktuella länkar och QR-koder långlivade utan att historiken går förlorad eller blandas ihop med gällande information.
