## Problem Statement

Moälvens IBK:s ledare behöver snabbt kunna avgöra vad som gäller inför och under en match utan att leta i flera regelböcker, matriser, lokala bestämmelser och föreningsdokument. Informationen skiljer sig mellan säsonger, nivåer och divisioner, och det är lätt att blanda ihop nationella regler, Västernorrlands distriktsanpassningar och Moälvens föreningsvägledning. Den nuvarande webbappen är ett tomt Astro-startprojekt, medan det första innehållet ligger som fristående dokument som inte går att använda som en sammanhängande mobil ledarguide.

## Solution

Bygg en publik, svensk och statiskt genererad ledarguide för säsongen 2026/27. Startsidan leder snabbt till röd eller blå nivå, Matchdagen samt Regler och dokument. Varje nivåguide visar de viktigaste matchfakta först, redovisar divisionsanpassningar utan duplicerad information och gör regelkällornas hierarki tydlig. Grön nivå visas som kommande tills materialet är verifierat. Webbplatsen följer Moälvens orange/svarta profil, fungerar mobil först och kan senare publiceras på valfri statisk hosting.

## User Stories

1. Som ledare vill jag se vilken säsong guiden gäller, så att jag inte använder gamla regler.
2. Som ledare vill jag välja grön, blå eller röd nivå direkt på startsidan, så att jag snabbt hittar relevant information.
3. Som ledare för röd nivå vill jag se det som är gemensamt för division 1–5, så att jag slipper läsa samma information flera gånger.
4. Som ledare för blå nivå vill jag se det som är gemensamt för division 6–7, så att jag får en tydlig utgångspunkt.
5. Som ledare vill jag se divisionsanpassningar separat, så att jag förstår exakt vad som skiljer min division från nivåguiden.
6. Som ledare vill jag se spelform, matchtid, planstorlek, målstorlek, domare och sekretariat högst upp, så att den viktigaste informationen är omedelbart tillgänglig.
7. Som ledare vill jag se både nationell regel och distriktsanpassning när de skiljer sig, så att jag förstår varför den lokala matchen genomförs annorlunda.
8. Som ledare vill jag tydligt kunna skilja nationell regel, distriktsanpassning och föreningsvägledning åt, så att råd inte misstolkas som bindande regler.
9. Som ledare vill jag se originalkälla för regelfakta, så att jag kan kontrollera uppgiften vid behov.
10. Som ledare vill jag se när varje faktagrupp senast kontrollerades, så att jag kan bedöma informationens aktualitet.
11. Som ledare vill jag se en varning när två aktuella källor verkar motsäga varandra, så att en osäker tolkning inte presenteras som säker.
12. Som ledare vill jag komma till en matchdagschecklista från startsidan, så att jag kan förbereda en hemmamatch utan att missa praktiska krav.
13. Som ledare vill jag kontrollera licenser, skyddsglasögon, iBIS och ledarlicens, så att laget är redo för match.
14. Som hemmaledare vill jag påminnas om matchvärdar och sekretariat, så att arrangemanget följer distriktets krav.
15. Som ledare vill jag hitta rutinen för matchflytt och länken till aktuell information, så att jag inte förlitar mig på inaktuella avgifter eller tidsgränser.
16. Som ledare vill jag hitta förbundets regelbok, ungdomsmatris och lokala bestämmelser samlade, så att jag kan gå vidare till originaldokumenten.
17. Som ledare vill jag se vad som är nytt för säsongen 2026/27, så att relevanta regeländringar inte missas.
18. Som ledare vill jag läsa en kort definition av bra matchmiljö, så att föreningens prioritering är synlig.
19. Som ledare vill jag nå förbundets material om bra matchmiljö, matchvärdar och ledarbeteende, så att jag kan fördjupa mig i rätt underlag.
20. Som styrelserepresentant vill jag att föreningens egna ledarprinciper väntar tills de har jämförts med befintliga riktlinjer, så att guiden inte publicerar obekräftad föreningspolicy.
21. Som besökare vill jag se att grön nivå finns i progressionen, så att nivåstrukturen är begriplig.
22. Som ledare för grön nivå vill jag se att guiden kommer senare, så att en tom eller gissad regelguide inte vilseleder mig.
23. Som mobilanvändare i hallen vill jag nå nivåer och matchdagen med få tryck, så att guiden fungerar under tidspress.
24. Som tangentbordsanvändare vill jag navigera hela webbplatsen med synligt fokus, så att innehållet är tillgängligt utan mus.
25. Som användare med nedsatt färgseende vill jag att nivå alltid uttrycks med både färg och text, så att färgen inte ensam bär betydelsen.
26. Som användare med reducerad rörelse aktiverad vill jag slippa onödiga animationer, så att webbplatsen är behaglig att använda.
27. Som ledare vill jag kunna skriva ut nivåguiden och matchdagschecklistan, så att jag kan ta med information utan separat PDF.
28. Som mobilanvändare vill jag se en kompakt meny med Hem, Nivåer, Matchdagen samt Regler och dokument, så att navigeringen är tydlig.
29. Som besökare vill jag slippa tomma sök- och kontaktkontroller, så att allt som ser interaktivt ut också fungerar.
30. Som klubbmedlem vill jag känna igen Moälvens orange/svarta profil, sköld och miljö, så att guiden känns som en del av föreningen.
31. Som innehållsansvarig vill jag ha en enda källa för varje text och regeluppgift, så att samma information inte behöver hållas synkron på flera platser.
32. Som innehållsansvarig vill jag att återkommande regelfakta valideras som strukturerade fält, så att saknade och felaktigt formaterade uppgifter upptäcks vid bygge.
33. Som innehållsansvarig vill jag förbereda nästa säsong som ett dolt utkast, så att ändringar kan kontrolleras innan publicering.
34. Som innehållsansvarig vill jag återanvända föregående säsongs struktur men återverifiera regeluppgifterna, så att gammal information inte oavsiktligt blir ny sanning.
35. Som innehållsansvarig vill jag aktivera en ny säsong genom ett medvetet publiceringsbeslut, så att säsongsskiftet inte sker automatiskt.
36. Som ledare vill jag att enkla adresser för röd och blå alltid visar aktuell säsong, så att bokmärken och framtida QR-koder fortsätter fungera.
37. Som historiskt intresserad användare vill jag senare kunna öppna en tidigare säsong via en permanent arkivadress, så att det går att se vad som gällde då.
38. Som användare vill jag att ett arkiv är oföränderligt och sekundärt till aktuell säsong, så att gammal information inte blandas ihop med gällande regler.
39. Som innehållsansvarig vill jag visa en kort uppdateringsnotis när något ändras under säsongen, så att ledare ser vad som har justerats och när.
40. Som framtida driftansvarig vill jag kunna publicera webbplatsen på Vercel, Netlify eller annan statisk hosting, så att implementationen inte låses till en leverantör.

## Implementation Decisions

- Lösningen byggs vidare på det befintliga Astro-projektet och genereras som en helt statisk webbplats.
- Första leveransen innehåller startsida, Röd nivå, Blå nivå, Matchdagen samt Regler och dokument.
- Grön nivå visas som kommande men får ingen egen guide innan källmaterialet är verifierat.
- Divisioner får inga egna publika sidor i första leveransen, men innehållsmodellen stödjer framtida divisionsvyer.
- En nivåguide äger de strukturerade fakta som är gemensamma för nivån. En division lagrar endast sina divisionsanpassningar.
- En framtida divisionsvy sammanfogar nivåguiden och divisionsanpassningarna vid generering; gemensamma regler dupliceras inte.
- Strukturerade fakta omfattar minst spelform, matchtid, plan, mål, domare, sekretariat, säsong, kontrolldatum och originalkällor.
- Innehållet valideras vid bygge. Overifierat eller ofullständigt innehåll får inte framstå som publicerat.
- Regelhierarkin modelleras och presenteras som nationell regel, distriktsanpassning och föreningsvägledning.
- När Västernorrland avviker från en nationell utgångspunkt visas båda formuleringarna, giltig nivå eller division, originalkälla och kontrolldatum.
- Motstridiga aktuella källor märks “Behöver bekräftas” tills distriktet har klargjort vad som gäller.
- Aktuell säsong nås via stabila nivåadresser. Säsongsbundna arkivadresser förbereds för framtida publicerade säsonger.
- Nästa säsong kan skapas som dolt utkast från samma struktur. Aktivering sker manuellt och gör den föregående säsongen till ett oföränderligt arkiv.
- Startsidan ordnas som hero, nivåväljare, Matchdagen, bra matchmiljö, regler och dokument samt framtida säsongsarkiv.
- Huvudnavigationen innehåller Hem, Nivåer, Matchdagen samt Regler och dokument. Sökning och kontakt utelämnas.
- Gränssnittet är mobil-först, på svenska och tillgängligt med tangentbord. Färg används aldrig som enda nivåsignal.
- Utskriftsregler ger rena versioner av nivåguider och checklistor utan separata PDF-filer.
- Moälvens orange/svarta profil används tillsammans med separata färger för röd, blå och grön nivå.
- Nivåväljaren är den visuella signaturen. Layouten använder sammanhängande nivåfält och tydliga avdelare i stället för en generell samling identiska kort.
- Lokalt paketerade typsnitt används; webbplatsen gör inga anrop till extern fonttjänst.
- Den godkända klubblogotypen används oförändrad bortsett från storlek. Publikbilden från Skyttis används som tillfällig hero och fotografens vattenstämpel behålls.
- Första versionen använder vanliga Astro-komponenter och lokal CSS utan klientramverk, konto, databas, CMS eller serverfunktioner.
- Webbplatsen innehåller ingen analys, cookies eller tredjepartsspårning.
- Hosting och domän ingår inte; bygget ska förbli kompatibelt med statisk hosting som Vercel eller Netlify.

## Testing Decisions

- Tester ska verifiera externt användarbeteende och publicerat innehåll, inte komponentstruktur, CSS-klasser eller intern datalagring.
- Den primära och enda nya testytan är browserbaserade acceptanstester mot en byggd produktionsversion av webbplatsen.
- Acceptanstesterna öppnar startsidan, Röd nivå, Blå nivå, Matchdagen samt Regler och dokument och följer verkliga navigationsvägar.
- Testerna verifierar synlig säsong, kontrolldatum, originalkällor och tydlig skillnad mellan nationell regel, distriktsanpassning och föreningsvägledning.
- Testerna verifierar att grön nivå uttryckligen visas som kommande och inte leder till en tom eller overifierad guide.
- Testerna verifierar centrala vyer på mobil och desktop, tangentbordsnavigering, synligt fokus och stöd för reducerad rörelse.
- Testerna verifierar att utskriftsläget behåller relevant innehåll och tar bort navigation och onödig dekoration.
- Astros produktionsbygge och innehållsvalidering används som grundkontroller men räknas inte som en separat testyta.
- Det finns ingen tidigare testpraxis i repositoryt att följa. En minimal browserbaserad acceptanstestyta introduceras därför på högsta möjliga nivå.

## Out of Scope

- Publicering till Vercel, Netlify eller annan hosting samt koppling av domän.
- Administratörsgränssnitt eller CMS.
- Konton, autentisering, databas och serverfunktioner.
- Sökfunktion och kontaktsida.
- Analys, cookies och tredjepartsspårning.
- Flerspråksstöd.
- Fullständig guide för grön nivå.
- Publika divisionssidor.
- Separata PDF-versioner.
- Egna fastslagna Moälven-principer för ledarbeteende innan de har jämförts med föreningens riktlinjer.
- Automatisk import eller tolkning av nya förbundsdokument.
- Automatisk kalenderstyrd aktivering av en ny säsong.

## Further Notes

- Vid konflikt gäller aktuella originaldokument från Svensk Innebandy eller Västernorrlands IBF enligt den uttryckliga regelhierarkin.
- Den aktuella Västernorrlands-matrisen visar en viktig distriktsanpassning på blå nivå: division 6 använder effektiv tid medan division 7 använder rullande tid och särskilda bytesregler under delar av säsongen. Detta ska framgå, inte döljas genom en alltför generell blå nivåguide.
- Röd nivå omfattar division 1–5 och blå nivå division 6–7. Grön nivå omfattar division 8–9 men skjuts upp.
- Öppna sakfrågor som inte blockerar första implementationen är verifiering av framtida grön nivå och jämförelse av föreslagna ledarprinciper med Moälvens befintliga riktlinjer.
- Domänspråk och arkitekturbeslut i repositoryts ordlista och ADR:er är styrande för implementationen.
